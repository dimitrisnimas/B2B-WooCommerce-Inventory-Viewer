# Security policy

This repository is a portfolio demonstration and the hosted viewer uses fictional local data only.

Please do not publish credentials in source code, frontend configuration, GitHub Actions output or generated Pages artifacts. Browser-delivered secrets are visible to every visitor.

If you discover a security issue in the reference plugin, report it privately to the repository owner instead of opening a public issue. Include the affected version, reproduction steps and expected impact.

Production users are responsible for defining an appropriate WordPress authentication policy and reviewing every field added through extension filters.
